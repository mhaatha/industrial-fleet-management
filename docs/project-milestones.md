# Project Milestones

Dokumen ini digunakan untuk melacak kemajuan pengembangan  proyek **Industrial Fleet Management System**, mencakup peta jalan *milestone* secara menyeluruh.



## 🗺️ Project Milestones

| Milestone | Modul / Fokus | Definition of Done (DoD) | Status |
| :---: | :--- | :--- | :---: |
| **M0** | **Project Bootstrap** | Go module, Docker, PostgreSQL, dan Redis berjalan dengan baik | 🔄 *In Progress* |
| **M1** | **Equipment Domain** | Domain model, *business rules*, dan unit tests selesai | ⏳ *Pending* |
| **M2** | **Equipment Persistence** | *Database migration* dan PostgreSQL repository terimplementasi | ⏳ *Pending* |
| **M3** | **Equipment REST API** | Endpoints CRUD, validasi payload, dan *integration tests* | ⏳ *Pending* |
| **M4** | **Telemetry Ingestion** | Ingestion API dan *event persistence* siap | ⏳ *Pending* |
| **M5** | **Telemetry Processing** | Outbox pattern, Redis Streams, dan worker pool berjalan | ⏳ *Pending* |
| **M6** | **Maintenance Engine** | Modul *scheduling* perawatan dan pengelolaan *work order* | ⏳ *Pending* |
| **M7** | **Authentication** | Mekanisme autentikasi (JWT/Session) dan RBAC terpasang | ⏳ *Pending* |
| **M8** | **Reliability** | Structured logging, *graceful shutdown*, dan pengumpulan *metrics* | ⏳ *Pending* |
| **M9** | **Integration & Deployment**| *Dockerized application* utuh dan pipeline CI/CD | ⏳ *Pending* |
